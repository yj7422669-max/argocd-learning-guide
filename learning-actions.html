02 / 설정과 결과

설정 한 줄이 실제 배포에서는 무엇이 될까요?

왼쪽 값을 클릭하면 오른쪽에서 해당 부분이 강조됩니다. 값도 바꿔보세요.

서비스별 values · 설명용 예시
같은 Helm 차트가 만든 실행 설정
차트 파일은 어떻게 나누나요?
Chart.yaml차트 이름과 버전values.yaml기본값 · 서비스마다 다른 값은 별도 values로 전달templates/Deployment · Service 같은 배포 파일 틀

Argo CD는 Helm으로 선언을 생성합니다. Helm이 별도의 실행 서버인 것은 아닙니다. DB·LiveKit 등은 앱 공통 차트와 범위를 따로 합의합니다.

    이미지
    앱과 실행 환경을 묶은 결과물
    파드 · Pod
    Kubernetes에서 컨테이너가 실행되는 단위
    네임스페이스
    클러스터 안의 리소스를 구분하는 공간
    동기화 · Sync
    원하는 선언을 실제 리소스에 반영하는 작업
    Synced
    Git 선언과 비교한 리소스 설정이 일치
    Healthy
    리소스가 상태 검사 기준으로 정상
    Self-heal
    활성화 시 수동 설정 변경을 Git 기준으로 되돌림
    Prune
    활성화 시 Git에서 빠진 리소스를 삭제하는 정책
